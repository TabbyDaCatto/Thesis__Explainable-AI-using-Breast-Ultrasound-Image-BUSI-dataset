# Thesis__Explainable-AI-using-Breast-Ultrasound-Image-BUSI-dataset

This repo contains the source code, Jupyter notebooks, and researches for my thesis regarding Explainable Artificial Intelligence (XAI) applied to breast cancer detection using ultrasound imaging

# Project Overview
Systems utilizing Deep Learning have shown extraordinary accuracy in medical imaging. However, their "black box" nature often limits explainability and clinical trust. This project focuses on bridging the gap by implementing and evaluating different Explainable AI (XAI) techniques on deep learning models trained to classify breast ultrasound images. By exploring the main reason why those models behave a certain way with a specific set of data, this work seeks out to make AI-driven clinical decisions more transparent and interpretable for healthcare professionals.

# Dataset
This research uses the Breast Ultrasound Image (BUSI) dataset, which consists of 2D ultrasound images categorized into 3 distinct classes:
- Normal: cases with no detected tumors
- Benign: non-cancerous tumors
- Malignant: cancerous tumors
